# Agents

Conventions for AI agents (and people) working on this project.

## Architecture overview

The app is a **zero-build static site**: plain HTML + CSS + vanilla JS served directly (GitHub Pages). No framework, no bundler, no server-side code. Files are classic `<script>` tags in global scope, loaded in the order listed in `index.html`.

### Data flow

```
editor text (JSON-LD, or Turtle → rete → JSON-LD)
   → JSON.parse → JsonLd.buildModel()          js/jsonld.js
   → buildGraphDataFromModel / buildSchemaGraphData   js/graph.js
   → ui.applyGraphData (Sigma) / diagram.render (SVG)
   → lintModel() → Problems tab + editor gutter js/lint.js
   → vocab.setDocumentModel() → Term Finder     js/vocab.js
```

`js/app.js` owns this state. Every structural edit (workbench, quick fixes, SHACL "Add to document") goes through `mutate(fn)`, which re-serialises the JSON and replaces the editor text with an undoable operation, then re-applies it.

### File layout

| Path | Purpose |
|---|---|
| `index.html` | DOM structure, CDN tags, script order |
| `css/styles.css` | Base layout and light/dark themes (CSS variables) |
| `css/workbench.css` | Menus, workbench, tools, diagram, editor syntax colours |
| `js/config.js` | Optional type/edge styling, ontology styles, prefixes, vocabulary catalog, search services, `RETE_CONFIG` (version pin) |
| `js/jsonld.js` | `JsonLd`: context processing, IRI expansion/compaction, `buildModel`, raw-document helpers |
| `js/graph.js` | Pure functions: network view, schema view (classes, shapes), legacy validation lookup |
| `js/layouts.js` | `createLayouts(graph, sigma)` |
| `js/panels.js` | `makePanelResizable()` for the editor and workbench |
| `js/editor.js` | `createEditor()`: CodeMirror (JSON-LD mode + overlay, Turtle mode), source index, autocomplete, problem markers |
| `js/ui.js` | `createUI()`: sidebar, details, tables, tool tabs, selection events. `escapeHtml`/`safeHref` — use them for any data rendered as HTML |
| `js/vocab.js` | `createVocabulary()`: term index, search, OLS/Wikidata, live vocabularies |
| `js/rete.js` | `Rete`: lazy engine loader, build/open, import/export, SPARQL, SHACL, term extraction, Turtle/JSON-LD serialisers |
| `js/lint.js` | `lintModel(model, vocab)` → problems with quick-fix actions |
| `js/ontology.js` | `createWorkbench(app)`: Find / Create / Library / @context |
| `js/tools.js` | `createTools(app)`: Problems, SPARQL, SHACL tabs |
| `js/io.js` | `createIO(app)`: templates, open, export, `.rete` dialog |
| `js/diagram.js` | `createDiagram(app, graph)`: box diagram with orthogonal connectors |
| `js/app.js` | Entry point and the `app` API given to the modules |
| `data/vocabularies/index.json` | Bundled term index — generated by `tools/build_vocab_index.py`, do not edit by hand |

## Conventions

- **No build step.** Every change must work by refreshing the browser.
- **CDN dependencies only, pinned to exact versions.** CodeMirror from cdnjs; Graphology, Sigma and `rete-graph` from jsDelivr. Do not add `node_modules` to the repo.
- **The rete engine is optional at runtime.** Load it only through `Rete.ensure()` (via the `Rete.*` functions), never at page load. Features that need it must say so while it loads.
- **Never insert document data with `innerHTML` unescaped.** Use `textContent`, or `escapeHtml()` / `safeHref()` from `js/ui.js`. JSON-LD files come from anywhere.
- **Document edits go through `app.mutate()`** so they stay undoable and re-render everything.
- **Config is optional.** Any JSON-LD must render without entries in `js/config.js`.
- **Factory functions** (`createEditor`, `createUI`, …) capture dependencies via closure; avoid new globals other than the module factories.
- `window.jsonldEditor` exposes `{ app, state, vocab, Rete, JsonLd, sigma, graph }` for debugging in the console.

## Testing

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

Check:
1. The sample renders; the Problems tab lists the 5 invalid membership IRIs; *Verify with rete* reports them missing.
2. Layouts (Force / Circular / Radial / Grid), the schema view 🧬, the box diagram ▭ and external IRIs 🌐.
3. Editor: syntax colours, Ctrl+Space suggestions, live apply, Turtle view round trip, resizing (drag the edge, ⇔), undo after a workbench edit.
4. Workbench: search "creator"; select a Person → *Add property*; Create a class (the reuse hint appears) and an instance.
5. New → Ontology starter; SHACL tab → Generate from ontology → Add to document → Validate.
6. Export Turtle / N-Triples / `.rete` with a card; re-open the `.rete` file.
7. Dark theme.
