JSON-LD Explorer

Interactive linked-data graph visualisation

  • 🔍
    Search — type in the sidebar to find nodes by name or ID.
  • 🎨
    Filters — toggle entity types via the checkboxes.
  • 🖱️
    Interact — click a node to see details; hover for a tooltip.
  • ✋
    Drag mode — enable with the ✋ button, then drag nodes.
  • 📝
    JSON-LD Editor — open the built-in editor, make changes, and click Apply.
  • 📊
    Data table — expand the bottom panel to browse nodes by type.
  • ⊞
    Layouts — switch between Force Atlas, Circular, Radial, and Grid.
  • ⌨️
    Keyboard — press Esc to close modals.
